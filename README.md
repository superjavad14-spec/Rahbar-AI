# Rahbar-AI

دستیار پژوهشی فارسی برای جست‌وجو و پاسخ‌گویی مستند بر پایه اسناد تأییدشده.

> این پروژه مستقل و غیررسمی است و وابستگی سازمانی یا نمایندگی از دفتر هیچ مقام یا نهادی را ادعا نمی‌کند.

## وضعیت پروژه

پروژه در مرحله آماده‌سازی رابط کاربری است. در این نسخه هنوز ورود ایتا، اتصال مدل هوش مصنوعی، پایگاه دانش و ذخیره تاریخچه فعال نیستند.

## مسیر کلی

- رابط کاربری: وب‌اپلیکیشن فارسی و راست‌چین؛ قابل اجرا در مرورگر و WebView برنامک ایتا
- احراز هویت: سازوکار رسمی برنامک ایتا با اعتبارسنجی اطلاعات در سمت سرور
- پردازش اسناد: استخراج متن و شماره صفحه از PDFها با ابزار محلی
- پایگاه داده و جست‌وجوی اسناد: Supabase و pgvector
- سرویس پاسخ‌گویی: Backend امن و اتصال به مدل از طریق Apinex

## اصول پاسخ‌گویی

- پاسخ‌ها باید به اسناد تأییدشده و قابل ارجاع متکی باشند.
- عنوان سند و شماره صفحه منابع نمایش داده شود.
- نقل‌قول مستقیم از خلاصه یا تحلیل مدل تفکیک شود.
- در نبود منبع کافی، عدم قطعیت صریحاً اعلام شود.
- محتوای اسناد، داده تلقی می‌شود و نباید دستورهای درون سند بر رفتار سامانه اثر بگذارد.

## ساختار پوشه‌ها

- `frontend/`: رابط کاربری
- `backend/`: API و منطق سمت سرور
- `ingestion/`: استخراج و آماده‌سازی PDFها
- `database/`: ساختار جداول و سیاست‌های دسترسی
- `docs/`: راهنمای نصب و مدیریت

## امنیت

کلیدهای API و رمزهای سرویس نباید در کد فرانت‌اند یا مخزن GitHub قرار بگیرند. آن‌ها فقط در Secretهای محیط Backend نگهداری خواهند شد.
